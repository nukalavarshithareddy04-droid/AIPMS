# AIPMS — AI-Powered Internship & Project Management System

Frontend for **Krishnova LLP · Technology Division**, built from `Documentation.Final.docx`.

React + TypeScript + Vite + Tailwind. Six role-aware workspaces (Admin, Mentor, Intern, HR, Executive, AI) covering the spec: projects, tasks, attendance, daily stand-ups, multi-agent AI, recruitment, learning, certificates, reports.

## Live demo

Anyone can open this (no install needed):

**https://lnr-7.github.io/aipms/**

Source: **https://github.com/lnr-7/aipms**

## Run it locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## What’s inside

- Cinematic marketing landing
- JWT-style RBAC shell (local demo auth)
- Dashboards matching the spec mockups
- Kanban tasks, live check-in, stand-up NLP flags
- AI Mentor, resume analyzer, skill gap, interview prep, risk scores
- Certificates with verification codes, learning paths, recruitment funnel
